Modelo OSI y capa física (6)

1.Verdadero o falso

En el modelo OSI, la unidad de datos de la capa de sesión se llama segmento.

  1. VVerdadero
  2. FFalso
Ver respuesta

Falso. En sesión, presentación y aplicación es el mensaje (SPDU, PPDU, APDU). El segmento es de transporte.

2.Opción múltiple

Las capas de red y transporte del modelo OSI se agrupan en la función de:

  1. a)comunicación
  2. b)networking
  3. c)servicios
  4. d)presentación
Ver respuesta

b) networking. Física y enlace = comunicación; sesión, presentación y aplicación = servicios.

3.Opción múltiple

¿Qué subcapa de enlace se encarga del control de flujo y del chequeo de errores?

  1. a)MAC
  2. b)LLC
  3. c)SAP
  4. d)PHY
Ver respuesta

b) LLC. MAC se ocupa del acceso al medio y del direccionamiento físico.

4.Verdadero o falso

La señalización broadband utiliza toda la capacidad del medio para una sola señal y se usa en LAN.

  1. VVerdadero
  2. FFalso
Ver respuesta

Falso. Eso es baseband (digital, TDM, LAN). Broadband comparte el ancho de banda entre varios canales analógicos con FDM y se usa en WAN.

5.Opción múltiple

La capa OSI llamada "el traductor" y que define el código ASCII o EBCDIC es:

  1. a)aplicación
  2. b)sesión
  3. c)presentación
  4. d)transporte

c) presentación. También comprime y encripta.

6.Opción múltiple

El medio con peor comportamiento frente a la EMI es:

  1. a)fibra

Falso. Física en estrella (todos a la MSAU), lógica en anillo.

12.Verdadero o falso

Polling es un método de contención.

  1. VVerdadero
  2. FFalso
Ver respuesta

Falso. Es determinístico, maestro-esclavo.

13.Opción múltiple

¿Qué variante de CSMA usa Ethernet?

15.Verdadero o falso

TCP/IP es una norma de comunicación.

  2. FFalso

Falso. Es una suite de protocolos de comunicación.

16.Verdadero o falso

IEEE 802.11 define la velocidad, la banda de frecuencia y el método de acceso al medio de una red inalámbrica.

  1. VVerdadero
  2. FFalso
Ver respuesta

Verdadero. Eso es exactamente lo que fija una norma.

Verdadero. 802.3 → 802.11 y CSMA/CD → CSMA/CA; IP, TCP, DHCP y DNS siguen iguales.

18.Verdadero o falso

CSMA/CD es un protocolo de comunicación.

  1. VVerdadero
  2. FFalso

Falso. Es un protocolo de acceso al medio, definido dentro de la norma 802.3.

Ethernet 802.3 y sus variantes (12)

23.Verdadero o falso

10GBASE-T puede trabajar en half-duplex con CSMA/CD.

  1. VVerdadero
  2. FFalso

Falso. Es solo full-duplex.

24.Opción múltiple

100BASE-TX corresponde a:

  1. a)802.3i
  2. b)802.3u
  3. c)802.3ab
  4. d)802.3an
Ver respuesta

b) 802.3u. Fast Ethernet. 802.3i = 10BASE-T, 802.3ab = Gigabit, 802.3an = 10 Gigabit.

25.Opción múltiple

En "10BASE2", el 2 indica:

  1. a)2 pares
  2. b)coaxil fino, ~200 m
  3. c)2 Mbps
  4. d)capa 2

b) coaxil fino, ~200 m. El valor exacto de la norma es 185 m; el "2" sale de redondear a 200.

26.Opción múltiple

Cable mínimo para 10GBASE-T a 100 m:

  1. a)Cat 5
  2. b)Cat 5e
  3. c)Cat 6
  4. d)Cat 6A
Ver respuesta

d) Cat 6A. Cat 6 llega a 10G solo hasta unos 55 m.

27.Opción múltiple

El tamaño mínimo de una trama Ethernet 802.3 es:

  1. a)46 bytes
  2. b)64 bytes
  3. c)1500 bytes
  4. d)1518 bytes
Ver respuesta

b) 64 bytes. 46 es el mínimo del campo de datos (por eso el padding); 1500 el máximo de datos; 1518 el máximo de trama.

28.Opción múltiple

En una trama Ethernet II, el campo de 2 bytes después de la MAC origen indica:

  1. a)la longitud de los datos
  2. b)el tipo de protocolo transportado
  3. c)el CRC
  4. d)la prioridad
Ver respuesta

b) el tipo de protocolo transportado. En una trama 802.3 ese campo indica la longitud de los datos.

29.Opción múltiple

Según la regla 5-4-3, entre dos PCs no puede haber más de:

  1. a)5 repetidores, 4 segmentos, 3 hubs
  2. b)5 segmentos, 4 repetidores, 3 segmentos poblados
  3. c)5 hubs, 4 switches, 3 routers
  4. d)5 PCs por segmento
Ver respuesta

b) 5 segmentos, 4 repetidores, 3 segmentos poblados. Son 5 segmentos en serie, 4 repetidores y 3 segmentos poblados (con PCs). Acota el retardo de propagación dentro de un mismo dominio de colisión para que CSMA/CD pueda detectar las colisiones.

33.Opción múltiple

¿Qué variante de Fast Ethernet usa 4 pares de UTP Cat 3 y solo funciona en half duplex?

Redes inalámbricas 802.11 (6)

35.Verdadero o falso

En una red Wi-Fi ad hoc todo el tráfico pasa por el access point.

  1. VVerdadero
  2. FFalso
Ver respuesta

Falso. En ad hoc los nodos se comunican peer to peer, sin AP. Eso describe el modo infraestructura.

36.Opción múltiple

Una estación cree que el canal está libre pero está ocupado por un nodo que ella no oye. Es el problema del:

  1. a)nodo expuesto
  2. b)nodo oculto
  3. c)bucle
  4. d)broadcast storm
Ver respuesta

b) nodo oculto. Lo mitiga RTS/CTS.

37.Opción múltiple

El orden correcto para conectarse a un AP es:

  1. a)asociación, escaneo, autenticación
  2. b)autenticación, escaneo, asociación
  3. c)escaneo, autenticación, asociación
  4. d)escaneo, asociación, autenticación
Ver respuesta

c) escaneo, autenticación, asociación. Primero se descubre el AP (escaneo pasivo con beacons o activo con probe request), después se confirma la identidad (autenticación Open System o Shared Key) y por último se asocia (velocidades, SSID, ID de asociación).

38.Verdadero o falso

Ocultar o cambiar el SSID es una medida de seguridad suficiente.

  1. VVerdadero
  2. FFalso
Ver respuesta

Falso. El SSID solo identifica y agrupa lógicamente la red. La seguridad la dan WPA2/WPA3 (AES).

39.Opción múltiple

La antena que da cobertura de 360° con menor alcance es la:

  1. a)direccional
  2. b)sectorial
  3. c)omnidireccional
  4. d)parabólica
Ver respuesta

c) omnidireccional. Cubre 360°, por eso tiene menos alcance. La direccional concentra la señal en un sentido y llega más lejos.

40.Opción múltiple

El material que más atenúa la señal Wi-Fi es:

  1. a)madera
  2. b)yeso
  3. c)ladrillo
  4. d)metal
Ver respuesta

d) metal. Los metales (vigas, armarios) tienen interferencia muy alta. Madera, vidrio y yeso, baja; ladrillo, media.

MAC, dispositivos y dominios (9)

41.Verdadero o falso

El switch separa dominios de broadcast.

  1. VVerdadero
  2. FFalso
Ver respuesta

Falso. Separa dominios de colisión. El broadcast lo separa el router (o las VLAN).

42.Verdadero o falso

El switch aprende las direcciones mirando la MAC destino de las tramas.

  1. VVerdadero
  2. FFalso
Ver respuesta

Falso. Aprende con la MAC origen. La destino la usa para decidir el reenvío.

43.Verdadero o falso

La dirección MAC tiene 32 bits.

  1. VVerdadero
  2. FFalso
Ver respuesta

Falso. 48 bits (6 bytes). 32 bits tiene la IPv4.

44.Verdadero o falso

Al reemplazar hubs por switches aumenta la cantidad de dominios de colisión.

  1. VVerdadero
  2. FFalso
Ver respuesta

Verdadero. Pasa de uno grande a uno por puerto: hay más, pero más chicos y sin choques. El de broadcast sigue siendo uno.

45.Verdadero o falso

Un hub trabaja en la capa 2 del modelo OSI.

  1. VVerdadero
  2. FFalso
Ver respuesta

Falso. Capa 1. Es un repetidor multipuerto.

46.Verdadero o falso

Cuando el switch hace flooding, la trama se convierte en broadcast.

  1. VVerdadero
  2. FFalso
Ver respuesta

Falso. Sigue siendo unicast; las placas que no son el destino la descartan.

47.Opción múltiple

Dispositivo que separa dominios de broadcast:

  1. a)hub
  2. b)repetidor
  3. c)switch
  4. d)router
Ver respuesta

d) router. Cada interfaz del router es una red distinta y no reenvía broadcasts. Hub y repetidor (capa 1) no separan nada; el switch separa solo colisión.

48.Opción múltiple

Switch con 2 PCs directas y un hub en un tercer puerto con 3 PCs. Dominios de colisión y de broadcast:

  1. a)5 y 1
  2. b)3 y 1
  3. c)1 y 1
  4. d)3 y 3
Ver respuesta

b) 3 y 1. 3 de colisión (dos puertos con PC + el puerto del hub, donde las 3 comparten uno) y 1 de broadcast (no hay router).

49.Opción múltiple

En Token Ring, el dispositivo que mantiene el anillo cerrado cuando una PC se apaga es:

  1. a)el Monitor Activo
  2. b)la MSAU, con sus relés de bypass
  3. c)el token
  4. d)el router
Ver respuesta

b) la MSAU, con sus relés de bypass. El Monitor Activo vigila el token, no el cableado.

Switching, STP y VLAN (4)

50.Opción múltiple

¿Qué protocolo evita los bucles entre switches?

  1. a)VLAN
  2. b)STP (802.1D)
  3. c)802.1Q
  4. d)ARP
Ver respuesta

b) STP (802.1D). Bloquea los puertos redundantes y deja un árbol sin bucles.

51.Opción múltiple

En STP, el switch raíz es el que tiene:

  1. a)mayor velocidad
  2. b)menor ID (prioridad + MAC)
  3. c)más puertos
  4. d)mayor MAC
Ver respuesta

b) menor ID (prioridad + MAC). El ID del switch es la prioridad (configurable) más su MAC; gana el menor. Después cada switch elige su puerto raíz por menor costo y se bloquean los puertos no designados.

52.Verdadero o falso

Cada VLAN es un dominio de broadcast y para comunicar dos VLANs hace falta un router.

  1. VVerdadero
  2. FFalso
Ver respuesta

Verdadero. Una VLAN divide el switch en switches virtuales: cada una es un dominio de broadcast distinto y, como el switch es de capa 2, pasar de una VLAN a otra requiere un router (capa 3).

53.Opción múltiple

¿Cuántos bits del encabezado 802.1Q identifican la VLAN?

  1. a)8
  2. b)12
  3. c)16
  4. d)32
Ver respuesta

b) 12. Son 12 bits de VLAN-ID dentro de la etiqueta de 4 bytes que va después de la MAC origen.

Tipos de LAN y servidores (4)

54.Verdadero o falso

En una red peer to peer cada PC es cliente y servidor a la vez.

  1. VVerdadero
  2. FFalso
Ver respuesta

Verdadero. Todas las PCs son iguales: cada una ofrece y pide recursos. Por eso los usuarios son locales y la administración se hace PC por PC.

55.Verdadero o falso

En una red de servidor dedicado los recursos compartidos solo pueden estar en el servidor.

  1. VVerdadero
  2. FFalso
Ver respuesta

Falso. Pueden estar en el servidor o en cualquier nodo del dominio; lo centralizado es la administración.

56.Verdadero o falso

Los permisos de recurso compartido se aplican también cuando el usuario accede localmente a la carpeta.

  1. VVerdadero
  2. FFalso
Ver respuesta

Falso. Solo se validan en el acceso remoto por la red.

57.Opción múltiple

¿Qué servidor asigna automáticamente las direcciones IP?

  1. a)DNS
  2. b)DHCP
  3. c)Proxy
  4. d)Dominio
Ver respuesta

b) DHCP. DNS resuelve nombres.

¿Cuál de estos es un protocolo de enrutamiento?

  1. a)IP
  2. b)RIP
  3. c)TCP
  4. d)ARP

b) RIP. También IGRP. IP es un protocolo ruteable: viaja con los datos.

66.Verdadero o falso

IP es un protocolo orientado a conexión y confiable.

  1. VVerdadero
  2. FFalso
Ver respuesta

Falso. IP es sin conexión y no confiable. TCP es el orientado a conexión y confiable.

67.Opción múltiple

Los pasos del three-way handshake de TCP son:

  1. a)ACK, SYN, FIN
  2. b)SYN, SYN-ACK, ACK
  3. c)GET, POST, PUT
  4. d)Discover, Offer, Request, Ack
Ver respuesta

b) SYN, SYN-ACK, ACK. Primero SYN, después SYN-ACK y por último ACK. La opción d) es el proceso DORA de DHCP.

68.Opción múltiple

¿Qué protocolo usa ping?

  1. a)TCP
  2. b)UDP
  3. c)ICMP
  4. d)ARP
Ver respuesta

c) ICMP. Ping envía un Echo Request y espera un Echo Reply, los dos mensajes ICMP.

69.Opción múltiple

Una PC muestra en ipconfig la dirección 169.254.12.5. Significa que:

  1. a)es una IP pública
  2. b)es loopback
  3. c)no consiguió configuración IP (por ejemplo, falló el DHCP)
  4. d)es multicast
Ver respuesta

c) no consiguió configuración IP (por ejemplo, falló el DHCP). Es una dirección de enlace local (APIPA).

70.Opción múltiple

Red 192.168.1.0 con máscara 255.255.255.192 (/26). ¿Cuántas subredes se obtienen y cuántos hosts utilizables tiene cada una?

  1. a)4 subredes de 64 hosts
  2. b)4 subredes de 62 hosts
  3. c)2 subredes de 126 hosts
  4. d)6 subredes de 30 hosts
Ver respuesta

b) 4 subredes de 62 hosts. Se prestan 2 bits → 22 = 4 subredes. Quedan 6 bits de host → 26 − 2 = 62 hosts. El salto es 256 − 192 = 64: la segunda subred es 192.168.1.64 y su broadcast es 192.168.1.127. Ojo: 64 es el salto, no la cantidad de hosts.
